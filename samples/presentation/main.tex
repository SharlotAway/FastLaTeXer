\begin{abstract}
FastLaTeXer 将文件树、源码编辑器和 PDF 预览放在同一个窗口中。
它通过本机 TeX Live 编译文档，支持源码与 PDF 双向定位、项目内补全和 Git 历史浏览。
配置好所需宏包和字体后，可离线编辑中文、英文及中英混排文档。
\end{abstract}
